# Olist E-Commerce SQL Analysis

## 📌 Project Overview

This project analyzes the Olist Brazilian e-commerce dataset using SQL to uncover business insights across sales, customers, products, sellers, payments, reviews, and logistics.

The analysis focuses on transforming raw transactional data into meaningful business insights through data validation, exploratory analysis, advanced SQL techniques, and business-oriented interpretation.

---

## 🎯 Business Objective

The objective of this project is to understand the key drivers of e-commerce performance and answer important business questions related to:

- Sales and order performance
- Customer behavior
- Product and category performance
- Seller performance
- Payment behavior
- Customer reviews
- Delivery and logistics
- Business growth and trends

---

## 🗂️ Dataset

The project uses the Brazilian E-Commerce Public Dataset by Olist.

The database contains the following tables:

| Table | Records |
|---|---:|
| customers | 99,441 |
| orders | 99,441 |
| order_items | 112,650 |
| order_payments | 103,886 |
| order_reviews | 99,224 |
| products | 32,951 |
| sellers | 3,095 |
| product_category_translation | 71 |
